# Drop-in payment verification

Paid remains a player claim in registrations. payment_reviews is the separate verification state. Its SELECT policy permits only the owner or Admin. Browser roles have no write grants. Internal checker functions and raw deposit allocations are in the private kestrel_payments schema, unavailable to clients. Admin verification requires auth.uid(), is_admin(), a valid current booking and a note, and appends an audit entry.

The existing hourly Kestrel payment checks task reads Gmail and calls kestrel_payments.record_result through the connected Supabase SQL tool. It does not change registrations, ban accounts or email players. It must inspect authenticated Interac plain-text deposited confirmations, resolve booking identity/date/fee and consult deposit_allocations before accepting a reference. The function enforces amount and transfer uniqueness, exact approved-group membership and totals. Ambiguous payments are reviewed by Admin. Partial payments or multiple transfers require manual review; do not bypass ledger checks.

New Paid claims start pending with a real paid_marked_at timestamp; older claims retain null and use cycle_started_at for a fresh observation allowance. A missing/ambiguous match cannot become red until 60 minutes have elapsed. Green is never downgraded by a missing-match check. Admin decisions are protected. A new red flag queues one email to the club Admin per claim cycle. The existing email dispatcher runs every minute. Connection errors must leave existing flags intact.

Players tap the flag for its explanation and use Message Admin to open a booking-linked form inside Messages. submit_payment_review_message validates ownership, reuses a single conversation for the review cycle, and writes the message atomically; the existing message trigger emails Admin. Admin checks Payment Review and the conversation, then marks verified with a note. No automated bans or accusations are part of this feature.

Scope: upcoming open/available paid drop-ins to academynewstar@gmail.com, excluding London volleyball and exact approved Season schedule/court assignments; other London sports stay included. The audit task checks seven days ahead. Changes of registration session, payment or attendance reset/remove the review as appropriate. The checker prunes reviews that are no longer eligible. Deposit allocations are retained to prevent reuse.
